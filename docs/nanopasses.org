#+title: ΛPEG → LPeg-VM nanopass compiler
#+author: cpeg

A nanopass pipeline compiling a ΛPEG grammar to bytecode for the
LPeg-style parsing machine: S-expressions → surface patterns → core
patterns → resolved grammar → flat instruction list → optimized
instruction list → encoded bytevector.

The pipeline as a whole:

#+begin_example
      *  (S-expressions)
      │  parse
      ▼
  ΛPEG1  surface            full combinator set incl. sugar and hooks
      │  simplify            local algebraic rewrites
      │  desugar             sugar → core, fresh capture/memo ids
      ▼
  ΛPEG2  core               only combinators with direct templates
      │  inline              substitute small leaf definitions
      ▼
  ΛPEG3  flat               grammar resolved, explicit calls
      │  lower               the big pass: combinators → instructions
      ▼
  ΛPEG4  instruction list   flat, symbolic labels
      │  opt-head-fail       Choice + matcher → fused test
      │  opt-jumps           jump threading, tail calls
      ▼
      *  (bytevector — the serialized program)
        encode
#+end_example

Design choices:

- The IR carries *symbolic labels* only.  Byte offsets, the padding
  rule, set/error/checker table indices are all encode-time concerns
  and never appear in an intermediate language.
- All optimization decisions that need to inspect lowered code
  (disjoint heads, capture-late/full, search's skip heuristic) are
  made in =lower=, not in post-hoc peepholes, so the peepholes stay
  small and local.
- Fresh labels are gensym'd — label *names* never reach the output;
  only their resolved byte offsets do.
- Nested grammars: a grammar is itself a pattern form and may appear
  anywhere inside an expression; it compiles inline at that position
  in the instruction stream.

* ΛPEG1 (surface)

The surface language: every combinator the constructor API can build,
including the sugar forms =plus=, =opt=, =rep=, =search= that have no
direct lowering template.  Terminals: rule names as symbols, charsets
as opaque 256-bit byte sets (assume =charset?=, =charset-union=,
=charset-negate=, =charset-sub=, =charset-count=, =charset-has?=),
literals as byte strings.

Any subexpression may carry a *hook* — a host lambda attached to it
(the =hook= form).  Hooks are a declared-but-unprocessed extension:
the languages carry the form through, no pass inspects or transforms
it yet, and =lower= rejects it.  The eventual handling (when it
becomes the task) is expected to parallel captures/checkers: lower
the hook to a marker instruction and thread the lambdas through a
side table keyed by occurrence, so the compiler itself never needs to
look inside a lambda.

#+begin_src scheme
(define-language ΛPEG1
  (entry Program)
  (terminals
   (variable  (x))            ; rule names
   (integer   (n id))         ; counts; capture/memo ids (id may be #f pre-desugar)
   (byte-string (s))          ; literals, error messages
   (charset   (cs))
   (procedure (f)))           ; host lambda — opaque to the compiler
  (Pattern (p)
    ε                         ; the empty pattern
    (lit s)                   ; string literal
    (set cs)                  ; charset
    (any n)                   ; any n bytes
    (seq p ...)               ; concatenation (n-ary)
    (alt p ...)               ; ordered choice (n-ary, right-assoc)
    (star p) (plus p) (opt p)
    (not p) (and p)
    (rep p n)                 ; exactly n repetitions
    (search p)                ; first-occurrence search:  S ← p / . S
    (grammar x (def x p) ...) ; nested grammar, compiles inline
    (cap id p)                ; capture, {{ }} in the peg language
    (memo id p)               ; memoization, {{ }} in the peg language
    (hook f p)                ; attach host lambda f; unprocessed for now
    (emptyop n)               ; zero-width assertion flag mask
    (err s p)                 ; error message + recovery pattern
    (errf s)                  ; error message, no recovery: parse FAILS
    (call x))                 ; unresolved non-terminal
  (Def (d)
    (def x p))
  (Program (P)
    (program x d ...)))       ; start rule name + definitions
#+end_src

** parse — =* → ΛPEG1=

S-expressions into ΛPEG1 structures.  This is also where a future
=.peg= text front-end would plug in.

#+begin_src scheme
(define-pass parse : * (S-exp) -> ΛPEG1 ()
  (definitions
    ;; Term* : list-of-s-expressions -> list-of-ΛPEG1:Pattern
    (define (Term* ps) (map Term ps)))
  (Pattern : * (p) -> Pattern ()
    (with-output-language (ΛPEG1 Pattern)
      (old-match p
        ['ε            `ε]
        ['""           `ε]
        [(? byte-string? s)   `(lit ,s)]
        [('set ,cs)            `(set ,cs)]
        [('. n)                `(any ,n)]
        [('. )                 `(any 1)]
        [('seq ,ps ...)        `(seq ,(Term* ps) ...)]
        [('/ ,ps ...)          `(alt ,(Term* ps) ...)]
        [('* ,p)               `(star ,(Term p))]
        [('+ ,p)               `(plus ,(Term p))]
        [('? ,p)               `(opt ,(Term p))]
        [('! ,p)               `(not ,(Term p))]
        [('& ,p)               `(and ,(Term p))]
        [('rep ,p ,n)          `(rep ,(Term p) ,n)]
        [('search ,p)          `(search ,(Term p))]
        [('grammar ,start . ,defs) `(grammar ,start ,(parse-defs defs) ...)]
        [('{ ,id ,p })         `(cap ,id ,(Term p))]
        [('hook ,f ,p)         `(hook ,f ,(Term p))]
        [('err ,msg ,rec)      `(err ,msg ,(Term rec))]
        [('err ,msg)           `(errf ,msg)]
        [(? variable? x)       `(call ,x)]
        [_ (error 'parse-Pattern "got: ~a" p)])))
  (Program : * (P) -> Program ()
    (with-output-language (ΛPEG1 Program)
      (old-match P
        [('program ,start . ,defs)
         `(program ,start
                   ,(map (λ (d) (old-match d [('def ,x ,p) `(def ,x ,(Pattern p))])) defs)
                   ...)]
        [_ (error 'parse-Program "got: ~a" P)])))
  (Program S-exp))
#+end_src

** simplify — =ΛPEG1 → ΛPEG1=

Local, bottom-up algebraic rewrites applied before any node is
inspected.  Merges single-byte literals and sets across =alt=;
eliminates =ε= from =seq= and =alt=; rewrites =(! (set cs) .)= into a
complement set and =(! (set cs) (set cs'))= into a difference set;
collapses =(opt (star p))= to =(star p)=.  Hooks are transparent:
=(hook f p)= simplifies as =p= and keeps the hook on the result.

#+begin_src scheme
(define-pass simplify : ΛPEG1 (P) -> ΛPEG1 ()
  (definitions
    ;; merge : ΛPEG1:Pattern ΛPEG1:Pattern -> (or/c #f charset)
    ;;   If the two patterns are single-byte matchers combinable into
    ;;   one charset, that set; #f otherwise.
    (define (merge p1 p2) ...)
    ;; rewrite-not-seq : the (! matcher matcher) → set complement/difference
    (define (rewrite-not-seq p1 p2) ...))
  (Pattern : Pattern (p) -> Pattern ()
    [(alt ,p1 ,p2)
     ;; ε elimination first, then merge; (alt ε p) → p, (alt p ε) → (opt p)
     (cond [(ΛPEG1:ε? p1) (Pattern p2)]
           [(ΛPEG1:ε? p2) `(alt ,(Pattern p1) ε)]
           [(merge p1 p2) => (λ (cs) `(set ,cs))]
           [else `(alt ,(Pattern p1) ,(Pattern p2))])]
    [(seq ,p1 ,p2)
     (cond [(ΛPEG1:ε? p2) (Pattern p1)]
           [(ΛPEG1:ε? p1) (Pattern p2)]
           [else `(seq ,(Pattern p1) ,(Pattern p2))])]
    [(seq (not ,p1) ,p2) (rewrite-not-seq (Pattern p1) (Pattern p2))]
    [(opt (star ,p)) `(star ,(Pattern p))]
    [(opt ,p)        `(opt ,(Pattern p))]
    [(hook ,f ,p)    `(hook ,f ,(Pattern p))]
    [,else ,else]))
  (Program : Program (P) -> Program ()
    [(program ,x ,d ...) `(program ,x ,(Def* d) ...)]))
#+end_src

** desugar — =ΛPEG1 → ΛPEG2=

Eliminates the sugar and assigns fresh ids — the α-rename analog.
=plus= becomes =p p*=; general =opt= becomes =p / ε= while
single-byte =opt= is kept for lowering to =test-char-nochoice= /
=test-set-nochoice=; =rep= expands to n copies; =errf= lowers to an
=error= instruction followed by =(end 1)= — the error is recorded and
the parse fails — while =(err s p)= records and continues with =p=.
=search= rewrites into its synthetic grammar =S ← p / . S=, with the
=[^r]*= skip prefix when =p= starts with a rare byte or a small set
(< 10 members).  Capture and memo ids that were =#f= on the surface
get fresh numbers from the same counter =lower= will use for
tree-memo ids.

The =search= grammar is emitted *inline at the reference site* (it is
a nested grammar), not lifted to the program's top level.

#+begin_src scheme
(define-pass desugar : ΛPEG1 (P) -> ΛPEG2 ()
  (definitions
    ;; fresh-id : -> integer        the shared cap/memo counter
    (define (fresh-id) ...)
    ;; search-grammar : ΛPEG2:Pattern -> ΛPEG2:Pattern
    ;;   the nested grammar  S ← p / . S   (or with the [^r]* skip
    ;;   prefix when p starts with a rare matcher)
    (define (search-grammar p) ...))
  (Pattern : Pattern (p) -> Pattern ()
    [(plus ,p)  (let ([p* (Pattern p)]) `(seq ,p* (star ,p*)))]
    [(opt ,p)
     (if (single-byte-matcher? p)
         `(opt ,(Pattern p))            ; lowers to a nochoice test
         `(alt ,(Pattern p) ε))]
    [(rep ,p ,n) (apply `seq (make-list n (Pattern p)))]
    [(cap #f ,p)      `(cap ,(fresh-id) ,(Pattern p))]
    [(cap ,id ,p)     `(cap ,id ,(Pattern p))]
    [(memo #f ,p)     `(memo ,(fresh-id) ,(Pattern p))]
    [(search ,p)      (search-grammar (Pattern p))]
    [(hook ,f ,p)     `(hook ,f ,(Pattern p))]
    ...)
  (Program : Program (P) -> Program ()
    ...))
#+end_src

* ΛPEG2 (core)

The core language: only the combinators that have a direct lowering
template in =lower=.  =plus=, =opt= (general), =rep=, =search= are
gone; every =cap= and =memo= carries a concrete integer id.  Grammar
structure is still by-name: =(call x)= may name a definition that has
not been (and may never be) emitted.

#+begin_src scheme
(define-language ΛPEG2
  (entry Program)
  (terminals
   (variable  (x))
   (integer   (n id))
   (byte-string (s))
   (charset   (cs))
   (procedure (f)))
  (Pattern (p)
    ε (lit s) (set cs) (any n)
    (seq p ...) (alt p ...)
    (star p) (opt p)                  ; opt only as single-byte sugar marker
    (not p) (and p)
    (grammar x (def x p) ...)
    (cap id p) (memo id p)
    (hook f p)                        ; carried through, unprocessed
    (emptyop n) (err s p)
    (call x))
  (Def (d) (def x p))
  (Program (P) (program x d ...)))
#+end_src

** inline — =ΛPEG2 → ΛPEG3=

Fixed-point inlining: any definition whose tree size is below the
threshold (100) and which references no remaining non-terminal is
substituted into every referencing =(call x)= site; repeat until
nothing changes.  A definition survives into the output if it is the
start rule or is still referenced by *any* surviving definition —
note this is "referenced by any def", not reachability from start, so
mutually-referencing dead defs are kept.  Output invariant: every
=(call x)= names a surviving =def=.

#+begin_src scheme
(define-pass inline : ΛPEG2 (P) -> ΛPEG3 ()
  (definitions
    (define inline-threshold 100)
    ;; def-size / def-leaf? : ΛPEG2:Def -> size / references-no-call?
    (define (def-size d) ...)
    (define (def-leaf? d) ...)
    ;; inline-once : (hash x → body) -> did-inline?
    ;;   substitute every (call x) whose def is small and leafy
    (define (inline-once env) ...)
    ;; collect-used : (hash x → body) -> set of still-referenced names
    (define (collect-used env) ...))
  (Pattern : Pattern (p) -> Pattern ()
    [(call ,x) (hash-ref inline-env x)]   ; when x is inlined away
    ...)
  (Program : Program (P) -> Program ()
    ;; loop inline-once to a fixed point, then emit start + used defs
    ...))
#+end_src

* ΛPEG3 (flat)

Same term language as ΛPEG2, but the grammar is resolved: the program
is exactly the set of definitions that will be emitted, each =(call
x)= names one of them, and no definition can be inlined further.
Nested grammars remain — they compile inline by =lower=.  The
distinction from ΛPEG2 is an invariant, not a syntax change — kept as
a separate language so =lower= can assume resolution rather than
check it.

#+begin_src scheme
(define-language ΛPEG3
  (entry Program)
  (terminals
   (variable  (x))
   (integer   (n id))
   (byte-string (s))
   (charset   (cs))
   (procedure (f)))
  (Pattern (p)
    ε (lit s) (set cs) (any n)
    (seq p ...) (alt p ...)
    (star p) (opt p)
    (not p) (and p)
    (grammar x (def x p) ...)         ; names a def of this program
    (cap id p) (memo id p)
    (hook f p)                        ; carried through, unprocessed
    (emptyop n) (err s p)
    (call x))                         ; names a def of this program
  (Def (d) (def x p))
  (Program (P) (program x d ...)))
#+end_src

** lower — =ΛPEG3 → ΛPEG4=

The big pass — the A-normalization analog.  Each combinator lowers to
a template of instructions with freshly gensym'd labels.  A grammar
lowers to =call start-label; jump Lend; label₀: body₀ return; ...;
Lend:= — and a *nested* grammar lowers exactly the same way, inline
at its position in the enclosing instruction stream.  Tail calls
(=call= followed by =return=) are resolved by the =opt-jumps=
peephole, not here.

Decided here, not by post-hoc peepholes:

- =Star= of a charset → single =span=.
- =Star= of a =memo= → the tree-memoization loop
  (=memo-tree-open= / =insert= / =tree= / =close=) with a fresh
  tree-memo id — the logarithmic skip structure for incremental
  reparses.
- Capture refinement: a leading run of =char= / =set= / =any= in the
  body is counted; if it covers the whole body → =capture-full= with
  that byte count, else the body head runs first and =capture-late=
  pushes mid-body, else the generic =capture-begin= ... =capture-end=.
  The count is an 8-bit operand: a prefix of 256+ bytes falls back to
  the generic form.
- Disjoint heads in =alt=: when the first real instructions of the two
  branches are =char= / =set= matchers that accept disjoint bytes, the
  =alt= lowers to =test-char-nochoice= / =test-set-nochoice= on the
  left branch's head — the test already consumed that matcher, so it
  is dropped from the left body.
- =(err s p)= lowers to =(error s)= followed by =p=; the fatal form
  (=errf=, desugared away) would be =(error s)= followed by =(end 1)=.

=(hook f p)= is rejected here for now — that is the extension point
where hook handling will be added later.

#+begin_src scheme
(define-pass lower : ΛPEG3 (P) -> ΛPEG4 ()
  (definitions
    ;; fresh-label : -> label    (gensym; never serialized)
    (define (fresh-label) ...)
    ;; insns-append : Insns ... -> Insns
    (define (insns-append . Iss) ...)
    ;; single-byte-matcher? : ΛPEG3:Pattern -> boolean
    (define (single-byte-matcher? p) ...)
    ;; lower-capture : id Insns -> Insns
    ;;   counts the leading constant-width run; full / late / begin+end;
    ;;   falls back to begin+end when the count reaches 256
    (define (lower-capture id I*) ...)
    ;; lower-alt-disjoint : Insns Insns -> (or/c #f Insns)
    ;;   the NoChoice form when branch heads are disjoint
    (define (lower-alt-disjoint l* r*) ...)
    ;; lower-star-memo : id Insns -> Insns
    ;;   the tree-memoization loop
    (define (lower-star-memo id I*) ...))
  (Pattern : Pattern (p) -> Insns ()
    (with-output-language (ΛPEG4 Insns)
      (nanopass-case (ΛPEG3 Pattern) p
        [ε            `(insns)]
        [(lit ,s)     `(insns ,(for/list ([c (in-bytes s)]) `(char ,c)) ...)]
        [(set ,cs)    `(insns (set ,cs))]
        [(any ,n)     `(insns (any ,n))]
        [(seq ,p ...) (apply insns-append (Pattern* p))]
        [(alt ,p1 ,p2)
         (define l2 (fresh-label)) (define l3 (fresh-label))
         (define l* (Pattern p1)) (define r* (Pattern p2))
         (cond [(lower-alt-disjoint l* r*) => values]
               [else
                `(insns (choice ,l2) ,l* ... (commit ,l3)
                             (label ,l2) ,r* ... (label ,l3))])]
        [(star (set ,cs)) `(insns (span ,cs))]
        [(star (memo ,id ,p))
         (lower-star-memo id (Pattern p))]
        [(star ,p)
         (define l1 (fresh-label)) (define l2 (fresh-label))
         `(insns (choice ,l2) (label ,l1) ,(Pattern p) ...
                 (partial-commit ,l1) (label ,l2))]
        [(opt ,p)                          ; single-byte only, by desugar
         (define l1 (fresh-label))
         (nanopass-case (ΛPEG3 Pattern) p
           [(lit ,s) `(insns (test-char-nochoice ,(bytes-ref s 0) ,l1)
                             (label ,l1))]
           [(set ,cs) `(insns (test-set-nochoice ,cs ,l1)
                              (label ,l1))])]
        [(not ,p)
         (define l1 (fresh-label))
         `(insns (choice ,l1) ,(Pattern p) ... (fail-twice) (label ,l1))]
        [(and ,p)
         (define l1 (fresh-label)) (define l2 (fresh-label))
         `(insns (choice ,l1) ,(Pattern p) ... (back-commit ,l2)
                      (label ,l1) (fail) (label ,l2))]
        [(cap ,id ,p) (lower-capture id (Pattern p))]
        [(memo ,id ,p)
         (define l1 (fresh-label))
         `(insns (memo-open ,l1 ,id) ,(Pattern p) ...
                 (memo-close) (label ,l1))]
        [(emptyop ,n) `(insns (empty ,n))]
        [(err ,s ,p)  `(insns (error ,s) ,(Pattern p) ...)]
        [(hook ,f ,p) (error 'lower "hooks not supported yet")]
        [(call ,x)    `(insns (call ,(def-label x)))])))
  (Program : Program (P) -> Prog ()
    ;; label each def, lower each body, wrap:
    ;;   call start-label; jump Lend;
    ;;   label₀: body₀ return; ... ;
    ;;   Lend:
    ...))
#+end_src

* ΛPEG4 (instruction list)

A flat list of instructions with *symbolic labels*.  No byte offsets,
no padding, no set-table indices, no checker indices: those are all
encode-time concerns and deliberately not in this language.  =nop=
exists as a deletion marker for the peepholes (it is never encoded).

Instruction semantics: the machine is a register =ip= / subject
position =sp= plus one heterogeneous stack holding backtrack points,
call return addresses, capture begin-markers, and memo bookkeeping
entries.  Failure is the control-flow mechanism: an instruction that
fails pops stack entries until a backtrack point is found, restoring
its =ip= and =sp= and discarding the abandoned branch's captures.

#+begin_src scheme
(define-language ΛPEG4
  (entry Prog)
  (terminals
   (u8        (c n))           ; byte operand, count, flag mask
   (i16       (id))            ; capture/memo ids
   (label     (l))             ; gensym'd symbols — never serialized
   (charset   (cs))
   (string    (msg)))          ; error messages
  (Insn (i)
    (label l)
    ;; matching — consume input or fail (span never fails)
    (char c) (set cs) (any n) (span cs) (empty n)
    ;; choice & backtracking
    (jump l) (choice l) (call l) (commit l) (return)
    (partial-commit l) (back-commit l) (fail) (fail-twice)
    ;; head-fail fused tests: check the head, consume on match,
    ;; jump to the alternative on mismatch
    (test-char c l) (test-char-nochoice c l)
    (test-set cs l) (test-set-nochoice cs l)
    (test-any n l)
    ;; captures
    (capture-begin id) (capture-late c id)
    (capture-end) (capture-full c id)
    ;; checkers — user validation of a matched span
    (check-begin id id) (check-end)
    ;; memoization — flat and tree variants
    (memo-open l id) (memo-close)
    (memo-tree-open l id) (memo-tree-insert) (memo-tree)
    (memo-tree-close id)
    ;; termination & deletion marker
    (error msg) (end n) (nop))
  (Insns (I*) (insns i ...))
  (Prog (P) (prog I*)))
#+end_src

** opt-head-fail — =ΛPEG4 → ΛPEG4=

Fuses a =choice= immediately followed by a =char= / =set= / =any=
into the corresponding =test= instruction, nop-ing the matcher whose
check the fused test already performed.  The two instructions must be
*strictly adjacent*: a =label= between them means something can jump
to the matcher, and the fusion would break that entry point.

#+begin_src scheme
(define-pass opt-head-fail : ΛPEG4 (P) -> ΛPEG4 ()
  (definitions
    ;; matcher? : ΛPEG4:Insn -> boolean     (char | set | any)
    (define (matcher? i) ...))
  (Insns : Insns (I*) -> Insns ()
    [(insns ,i ... (choice ,l) ,m . ,rest)
     (guard (matcher? m))
     (match m
       [(char c) `(insns ,i ... (test-char ,c ,l) (nop) . ,(Insns rest))]
       [(set cs) `(insns ,i ... (test-set ,cs ,l) (nop) . ,(Insns rest))]
       [(any n)  `(insns ,i ... (test-any ,n ,l) (nop) . ,(Insns rest))])]
    ...))
#+end_src

** opt-jumps — =ΛPEG4 → ΛPEG4=

Jump threading and tail calls:

- a =jump= whose target's next real instruction (skipping =label=s
  and =nop=s) is another control-flow instruction (=partial-commit=,
  =back-commit=, =commit=, =jump=, =return=, =fail=, =fail-twice=,
  =end=) is *replaced* by that instruction;
- a =call= immediately followed (no intervening =label=) by =return=
  becomes =jump= with the =return= nop-ed — the tail-call
  optimization.

#+begin_src scheme
(define-pass opt-jumps : ΛPEG4 (P) -> ΛPEG4 ()
  (definitions
    ;; label-target : Prog label -> index     (label → instruction index)
    (define (label-target P l) ...)
    ;; next-real : Prog index -> index        (skips label and nop)
    (define (next-real P from) ...)
    (define control-flow-ops
      '(partial-commit back-commit commit jump return fail fail-twice end)))
  (Insns : Insns (I*) -> Insns ()
    [(insns ,i ... (jump ,l))
     (guard (memq (insn-at P (next-real P (label-target P l)))
                  control-flow-ops))
     `(insns ,i ... ,(insn-at P (next-real P (label-target P l))))]
    [(insns ,i ... (call ,l) ,r ... (return))
     (guard (no-label-between? r))
     `(insns ,i ... (jump ,l) (nop))]
    ...))
#+end_src

** encode — =ΛPEG4 → *=

ΛPEG4 → a bytevector plus side tables.  Two phases, because label
targets are byte offsets and offsets depend on instruction sizes:

1. *size pass* — walk the insns, compute each instruction's encoded
   length from the pad rule (opcode byte, then one pad byte iff the
   argument-byte count is even, then arguments; jump targets are
   24-bit mixed-endian: =b[0]= bits 16–23, =b[1:3]= bits 0–15 LE),
   and build the =label → byte offset= map;
2. *emit pass* — walk again, writing operands, deduplicating charsets
   (side table, ≤ 256 entries) and error strings, numbering
   =(check-end)= occurrences in order (the checker indices the host
   must register to match — the checker functions themselves travel in
   a side table threaded from parse to encode, keyed by occurrence),
   and appending the terminating =(end 0)=.

The return value is the serialized program: bytevector, charset
table, error table, checker table — everything the parsing machine's
loader needs.  Pre-decoding (translating the byte stream into the
fixed-size executable form with jump targets as instruction indices)
is a loader-side concern, not a compiler-side one.

#+begin_src scheme
(define-pass encode : ΛPEG4 (P) -> * ()
  (definitions
    ;; encoded-size : Insn -> natural    (the pad rule, per-opcode sizes)
    (define (encoded-size i) ...)
    ;; emit-insn : Insn label→offset set-table error-table -> bytes+
    (define (emit-insn i offs sets errs) ...)
    ;; add-set / add-error : table charset|string -> index   (dedup)
    (define (add-set sets cs) ...)
    (define (add-error errs msg) ...))
  ;; 1. sizes → label→offset map
  ;; 2. emit  → bytevector + set/error/checker tables + (end 0)
  ...)
#+end_src
