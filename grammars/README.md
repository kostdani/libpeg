# grammars/

Text grammars, in the language of the tool that reads them, kept out of
the library sources so the corpus can be edited without a rebuild.

Purpose: the self-description and the test corpus (JSON, Java, Lua,
s-expression) that the front end parses and the differential suites
compare against.

Empty today — the `.peg` reader that consumes these is the front-end
track's work.
